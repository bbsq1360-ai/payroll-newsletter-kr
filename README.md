# 🇰🇷 한국 급여·노동법 뉴스레터

Claude AI가 최신 한국 노동법·급여 이슈를 실시간으로 검색하고 정리하는 뉴스레터 앱입니다.

## 기능

- **뉴스레터 자동 생성**: 버튼 하나로 최신 노동법·급여 뉴스 생성
- **3단계 분류**: 🔴 URGENT / 🟡 IMPORTANT / 🟢 FYI
- **관리자 페이지**: `/admin`에서 KEY NUMBERS 수치 직접 수정
- **한/영 병기**: 모든 항목 한국어 + 영어 설명

## 로컬 실행

```bash
npm install
cp .env.example .env.local
# .env.local에 API 키와 관리자 비밀번호 입력
npm run dev
```

## Vercel 배포

1. GitHub에 이 레포지토리 Push
2. [vercel.com](https://vercel.com)에서 GitHub 연동
3. 환경변수 설정:
   - `ANTHROPIC_API_KEY`: Anthropic API 키
   - `ADMIN_PASSWORD`: 관리자 페이지 비밀번호

## 사용 방법

- `/`: 뉴스레터 열람 (누구나 접근 가능)
- `/admin`: KEY NUMBERS 수정 (비밀번호 필요)
